## SQL Server: ориентир для переноса — 20.11.2026

Python-пилот уже работает с отдельной SQL-базой на DIMA. Перенос из тестового снимка сверен построчно и по итогам документов. На SQL Server проверены запись и конфликты правок, отмена и повтор, этапы, акты, корзина и восстановление из резервной копии. С SERV подтверждён доступ к порту 1433.
