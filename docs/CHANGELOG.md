# Журнал изменений C#

## 25.11.2026 — v0.1.5, MIG-REL-01, не опубликовано

- `src/GmcSmeta.Cli/SqlLive.cs`. Раньше CLI мог продолжить проверку после отрицательного результата проверки базы и пропустить скидку и ручную разбивку КС при отсутствии подходящих актов. Теперь неподходящая база отклоняется до подключения, а скидка и JSON разбивки записываются и перечитываются на временном акте подходящего договора. Прогон на выделенной v31 прошёл вместе с Undo/Redo.

- `tests/GmcSmeta.ContractExport.Checks/Program.cs` и `GoldenChecks.cs`. Добавлен импорт System.IO для сборки отдельного проекта. Проверка OOXML учитывает, что ведомость выдачи содержит готовые количества и не требует формул. Для форм КП проверка формул сохраняется. Оба экспортных прогона завершились успешно. Извлечение части PDF-текста пропущено без pdftotext.
- `src/GmcSmeta.Core/GmcSmeta.Core.csproj`. Транзитивный Pkcs 9.0.11 заменён прямым указанием версии 10.0.13 с исправлениями CVE-2026-70162 и CVE-2026-84008. Повторная сборка не выдала соответствующих предупреждений NuGet.
- `CURRENT_TASK.md`, `docs/MASTER_TODO.md`, `docs/SQL_MIGRATION_RELEASE_TODO.md`, `docs/PYTHON_0664_TO_0679_PARITY.md`. Записаны результаты миграции снимка, сборки, 1256 тестов, сверки с Python и оставшиеся проверки.
