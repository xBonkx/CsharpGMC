# Тестовый режим на настоящем SQL Server — 28.11.2026

Генератор в xBonkx/gmcsmeta tools/create_demo_databases.py строит схему 31 из ORM-моделей и отдельно схему 32 через штатную expand_v32.sql. Исходная база владельца 28 не читается и не изменяется.

- DEMO-01 PARTIAL: --demo <строгое имя> запускает обычный MainWindow, без штатного лаунчера и автообновления; центральный Open/OpenAsync проверяет имя, локальный физический сервер, Shared Memory, метку готовности и схему 32. Тесты добавлены, не запускались.
- DEMO-02 PARTIAL: общая генерация вымышленных КП, договоров, приложений, этапа, КС, выдачи, закупки и себестоимости; сценарий живого создания ещё не выполнен.
- DEMO-03/04 PARTIAL: используются штатные редакторы, вычисления и SQL-операции; отдельного демо UI нет. Требуется реальная интеграционная проверка всех вкладок, а не только открытие MainWindow.
- DEMO-05 PARTIAL: отдельный профиль и идентификатор приложения; корни ПТО/писем/паспортов изолированы. Дополнительный аудит путей и скрипт установки двух ярлыков.
- DEMO-06 NOT STARTED: удаление оставшихся исторических файловых реализаций, зависимостей, тестов и упоминаний после замены потребителей.
- DEMO-07 NOT STARTED: Windows/.NET/Python/Qt/WPF/SQL Server приёмка, EXE, сеть отключена, сценарии и масштаб.
