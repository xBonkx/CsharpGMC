## Правило завершения

Каждый F-ID имеет: ссылки на исходную функцию Python и C#-реализацию, проверку UI (не только наличие кнопки), офлайн-тесты, интеграционную проверку SQL на пилоте, при необходимости контроль Excel/PDF и скриншоты. Для задачи указывать **DONE / PARTIAL / BLOCKED / NOT STARTED**, а также фактические непроверенные пункты. Нельзя закрывать задачу по факту компиляции или появлению XAML.

**Изменения в рабочей базе и переход с Python запрещены до отдельного разрешения пользователя.** При каждом выполненном блоке — commit + push в `main`, сверка удалённого SHA и CI. Без добавления новых функций, отсутствующих в Python, до закрытия обязательного списка.
