## Статусы и обновление

- NOT STARTED — сверено, отсутствует реализация; UNVERIFIED — не выяснено; IN PROGRESS — задача взята и указаны агент/ветка/дата; PARTIAL — есть реализация части; CODE READY — все изменения внесены, приёмка не завершена; DONE — необходимые проверки фактически пройдены; BLOCKED — конкретный блокер; DUPLICATE — ссылка на канонический ID (не считать дважды); N/A — обоснованное и согласованное исключение.
- До работы читать свежий main, выбрать ID, не брать задачу занятую другим агентом; новый ID добавлять в реестр и исходный список. После каждого блока в том же коммите обновлять строки, доказательства (путь/коммит/результат и дата теста), остаток, сводку; обновлять соответствующий исходный TODO и CURRENT_TASK. Для будущего SHA допустима ссылка на файл/тест и commit текущего изменения после публикации, без самоссылочного SHA. Не закрывать чекбокс исходника до DONE.
- Статический анализ, сборка, офлайн, Windows GUI/DPI, SQL Pilot, измерения и экспорт — разные виды доказательств; фиксировать фактический результат и непройденные проверки.
