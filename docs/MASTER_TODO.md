- NOT STARTED — сверено, отсутствует реализация; UNVERIFIED — не выяснено; IN PROGRESS — задача взята и указаны агент/ветка/дата; PARTIAL — есть реализация части; CODE READY — все изменения внесены, приёмка не завершена; DONE — необходимые проверки фактически пройдены; BLOCKED — конкретный блокер; DUPLICATE — ссылка на канонический ID (не считать дважды); N/A — обоснованное и согласованное исключение.
- До работы читать свежий main, выбрать ID, не брать задачу занятую другим агентом; новый ID добавлять в реестр и исходный список.
