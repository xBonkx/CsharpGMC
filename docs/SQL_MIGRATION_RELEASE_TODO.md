
# Одна кнопка: выпуск релиза и миграция SQL Server

## Решение владельца от 25.11.2026
EXE «ГМЦ-Смета — собрать релиз» выполняет весь процесс одним нажатием.
Если схема не изменена, SQL Server не трогается. Если схема изменилась,
выпуск включает миграцию с резервной копией, без ручного набора команд.

## Текущее состояние / блокер
Обычная запись C# разрешена только на схеме 28. Схема 31 допускается
в отдельных preview/write-test режимах, а полноценный переход 28 → 31
владелец поручает Codex отдельно. SQLite Migrations.cs не применим к SQL Server.
Production Cutover по-прежнему запрещён; ограничения не снимать автоматически.
Сейчас релизный guard останавливает выпуск, если WritableSchemaVersion
отличается от approved-schema.txt. Это временная блокировка, не мигратор.
Не менять approved-schema.txt ради обхода. sql-schema-version.txt включён
в релиз и SHA256SUMS.
