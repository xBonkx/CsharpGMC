## SQL 28 → 31
Оригинальные SQL DDL Python сохранены без изменений в tools/sql-migrations. Новый C# SchemaRehearsal создаёт COPY_ONLY CHECKSUM backup, VERIFYONLY, отдельную восстановленную копию, применяет маршрут из 28/29/30 и проверяет версии, типы/NULL, число строк, DBCC CHECKDB, SHA-256 всех исходных значений в порядке первичных ключей (исключена только строка schema_version), сохранность исходной базы и начальные значения новых полей. Останавливается при активных сеансах; не отключает клиентов. На исходной базе DDL не выполняет. Поддерживает только явно названные Test_/ReleaseCheck_ базы и одно data/log устройство. Нет автоматического восстановления поверх исходника.
Запуск на Windows администратором после создания отдельной копии: задать GMC_SMETA_MIGRATION_CONNECTION (не в Git, не в логах), затем
`dotnet run --project tools/sql-migrations/GmcSmeta.SchemaRehearsal -- --test-only GmcSmetaPilot_Test_Migration28 --target 31`.
Остаётся проверить на настоящем SQL Server, восстановить/сверить финансовые данные, ввести maintenance gate, рабочую миграцию и возобновление релиза. Блокировка публикации схемы 31 остаётся. Никаких изменений рабочей БД.
