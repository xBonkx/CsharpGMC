## SQL 28 → 31
Оригинальные SQL DDL Python сохранены без изменений в tools/sql-migrations. Новый C# SchemaRehearsal создаёт COPY_ONLY CHECKSUM backup, VERIFYONLY, отдельную восстановленную копию, применяет маршрут из 28/29/30 и проверяет версии, типы/NULL, число строк и DBCC CHECKDB. На исходной базе DDL не выполняет. Поддерживает только явно названные Test_/ReleaseCheck_ базы и одно data/log устройство. Нет автоматического восстановления поверх исходника.
Запуск на Windows администратором после создания отдельной копии: задать GMC_SMETA_MIGRATION_CONNECTION (не в Git, не в логах), затем
`dotnet run --project tools/sql-migrations/GmcSmeta.SchemaRehearsal -- --test-only GmcSmetaPilot_Test_Migration28 --target 31`.
